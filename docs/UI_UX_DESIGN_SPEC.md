# UI/UX 개선 시안 명세

이 문서는 Figma 파일을 대신하는 구현 기준의 화면 명세다. 현재 저장소에는 Figma 링크나 원본 파일이 없으므로,
포트폴리오에는 이 문서와 실제 Production 캡처를 함께 제시한다.

## 디자인 시스템

| 항목      | 기준                                                                           |
| --------- | ------------------------------------------------------------------------------ |
| 톤        | 밝은 식물·정원 계열의 대시보드, 기록에 집중하는 낮은 밀도                      |
| 기본 표면 | 아이보리·연녹색 카드와 얇은 연녹색 테두리                                      |
| 클린식    | 녹색 계열 카드·라벨·이미지로 상태를 함께 표시                                  |
| 자유식    | 주황·적색 계열 카드·라벨·이미지로 상태를 함께 표시                             |
| 버튼      | 저장은 녹색 채움, 수정은 녹색, 삭제는 적색 테두리로 구분                       |
| 입력      | 텍스트 레이블, 포커스 외곽선, 오류 문구를 입력 가까이에 표시                   |
| 간격      | 카드 내부는 8px 단위의 간격을 우선하고, 모바일에서는 한 열로 전환              |
| 접근성    | 키보드 포커스 외곽선, 텍스트 상태 라벨, `aria-label`과 `aria-live` 피드백 제공 |

색만으로 상태를 전달하지 않고, 끼니 라벨·클린식/자유식 텍스트·상태 이미지를 함께 사용한다.

## 화면 1 — 오늘 기록

**목표:** 사용자가 오늘의 체중과 아침·점심·저녁·간식을 짧은 흐름으로 기록한다.

1. 이전·선택·다음 날짜를 한 줄로 보여 주는 날짜 행에서 기록일을 확인하고, 가운데 선택 날짜를 눌러 날짜 선택기를 연다.
2. 햄버거 메뉴의 `가져오기` 아래에서 목표 체중을 설정하고, 진한 초록색 체중 카드에서 오늘 체중과 목표 대비 남은 감량을 확인한다.
3. 각 식사 카드에서 음식명과 최종 분류를 선택한다.
4. 저장 후에는 `수정 | 삭제` 두 행동을 나란히 제공한다.

**핵심 상태:** 입력 전, 키워드 기반 제안 표시, 저장 중, 저장 완료, 수정 모드, 삭제 확인, 입력/저장 오류.
체중 오류 문구 영역은 미리 높이를 확보해, 문구가 나타나도 체중 입력 행과 저장 버튼이 움직이지 않게 한다.

## 화면 2 — 캘린더와 날짜 상세

**목표:** 월간 식단 상태를 훑고 특정 날짜의 네 끼 기록을 확인한다.

- 하루에 자유식이 하나라도 있으면 자유식 상태를 우선 표시한다.
- 모든 기록이 클린식이면 클린식 상태를 표시한다.
- 기록이 없는 날짜는 별도 상태 이미지 없이 Empty State 문구로 안내한다.
- 날짜 상세에는 음식명과 분류를 함께 표시해 색만 보고 판단하지 않게 한다.

## 화면 3 — 통계

**목표:** 최근 7일 기록을 숫자와 차트로 요약해, 달력을 직접 세지 않아도 패턴을 파악하게 한다.

- 상단: `최근 7일 리포트`, 기간 배지, 총 기록·클린식·자유식 3개 요약 카드
- 차트: 비율 도넛(클린식 비율 직접 표시), 날짜별 누적 막대, 기준선·영역 채움·체중 값을 함께 표시한 체중 꺾은선. 체중 값은 점 위의 전용 여백에, 날짜는 하단 전용 영역에 배치해 선·원·글자가 겹치지 않게 한다.
- 카드: 클린식은 녹색, 자유식은 주황색 계열로 구분하되 텍스트 라벨과 수치를 함께 표시
- 모바일: 요약 카드는 3열을 유지하고, 차트는 한 열로 쌓아 가로 스크롤을 방지
- 화면 상단: 요약 카드 없이 클린식/자유식 원형 비율 그래프를 바로 표시한다.
- Empty State: 기록이 부족하면 통계 숫자 대신 다음 기록 행동을 안내한다.

## 화면 4 — 모바일

390px 너비에서는 식사 카드를 한 열로 전환한다. 햄버거 메뉴의 목표 체중 입력, 식단 입력, `수정 | 삭제` 버튼, 캘린더 7열,
통계 차트가 가로 스크롤 없이 보이는지를 수동 테스트와 캡처로 확인한다.
