# 최근 추가 기능

2026-08-21 기준으로 오늘 기록 화면에 목표 체중과 식단 분류 보조를 추가했다.

## 목표 체중

- 사용자는 목표 체중을 입력하고 `설정` 버튼으로 적용한다.
- 저장된 목표가 있으면 버튼은 `수정`으로 표시된다.
- 현재 선택 날짜의 체중과 목표가 모두 있으면 `남은 감량 = max(현재 체중 - 목표 체중, 0)`을 표시한다.
- 목표 체중은 브라우저 `localStorage`에 저장되는 개인 기기 설정이다. 로그인 계정이나 서버 데이터베이스에는 저장하지 않는다.
- 이 기능은 감량 기간·속도·건강 상태를 예측하거나 의료 조언을 제공하지 않는다.

## 음식명 기반 분류 보조

- 이 기능은 AI 모델 또는 외부 API를 사용하지 않는다.
- [`src/components/mealKeywords.ts`](../src/components/mealKeywords.ts)의 클린식 허용 목록에만 포함된 음식명을 클린식으로 제안한다.
- 허용 목록에는 `공복`, 샌드위치·랩·또띠아 같은 간편식 표현과 단백질·통곡물·채소·과일·무가당 식품 표현을 폭넓게 포함한다.
- 목록에 없는 음식명은 자유식으로 제안한다. 튀김·크림·마요·소스 등 자유식 우선 키워드가 함께 있으면 클린식 단어가 포함돼도 자유식으로 제안한다.
- 제안은 기록값을 자동 변경하거나 저장하지 않는다. 사용자가 `클린식` 또는 `자유식` 버튼을 직접 선택한 뒤 저장해야 한다.
- 화면에서는 `키워드 기반 제안`으로 표시해 AI 추천처럼 오해하지 않도록 한다.

## 식단 기록 수정과 삭제

- 식단을 저장한 뒤에는 한 개의 저장 버튼 대신 `수정`과 `삭제` 버튼을 나란히 표시한다.
- `수정`은 입력 상태로 전환하고, `삭제`는 확인 후 해당 끼니 기록 하나만 삭제한다. 같은 날짜의 다른 끼니와 체중 기록은 유지한다.

## 검증 범위

- `getMealTypeSuggestion()` 단위 테스트는 빈 입력, 연어 포케(클린식 제안), 목록 밖 음식과 우선 키워드가 있는 음식(자유식 제안)을 확인한다.
- UI 변경은 `npm run lint`와 `npx tsc --noEmit`으로 확인한다.
