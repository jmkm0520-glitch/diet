# 수동 테스트 체크리스트

`portfolio subject.md` 18번의 Test 1~11에 대응하는 절차입니다.

로그인 세션이 필요해 자동화하지 않았습니다. 아래 항목은 **사람이 브라우저에서 직접 확인**해야 하며,
결과 칸에 통과 여부와 날짜를 적으면 그대로 포트폴리오의 테스트 근거가 됩니다.

자동으로 검증되는 부분(집계 규칙, 요약 문장, 캘린더 격자, CSV 파싱 등)은
`pytest api -q` 129개 수집과 `pnpm test` 62개 테스트 선언이 덮고 있습니다. 여기 있는 것은
**세션·다중 사용자·실제 배포 환경처럼 테스트 코드로 재현하기 어려운 것들**입니다.

대상: https://www.food-broccoli.shop

> **수행 기록 — 2026-08-20: Test 1~11 전부 통과.**
> 아래 표의 결과 칸은 다음 회차를 위해 비워 둡니다.

## Test 1 — 회원가입

1. 로그아웃 상태에서 접속
2. `계정이 없나요? 회원가입` 클릭
3. 이름·이메일·비밀번호 입력 후 `인증 메일 받기`
4. 메일의 6자리 인증번호 입력

| 확인할 것                                    | 결과 |
| -------------------------------------------- | ---- |
| 인증 메일이 실제로 도착한다                  |      |
| 인증번호 입력 후 오늘 기록 화면으로 넘어간다 |      |
| 새로고침해도 로그인 상태가 유지된다          |      |
| 화면 제목이 신규 가입자에게 어색하지 않다    |      |

> 개선 완료. 제목이 `첫 회원 만들기`로 고정돼 두 번째 이후 가입자도 "첫 회원"을 보던 것을
> `회원가입`으로 바꿨습니다. Before 증거는 `before-10-signup.png`입니다.
