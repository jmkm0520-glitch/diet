# 「오늘도 가볍게」 웹 개발 학습 가이드

이 문서 모음은 웹 개발을 처음 접하는 비전공자가 「오늘도 가볍게」 프로젝트의 전체 구조를 먼저
이해한 뒤, 각 영역을 하나씩 확대해서 학습할 수 있도록 돕는다.

처음부터 모든 기술 용어를 외우는 것이 목표가 아니다. 사용자의 행동이 프론트엔드, 백엔드,
데이터베이스를 어떻게 지나가는지 큰 흐름을 이해하고, 필요한 개념을 순서대로 연결하는 것이
목표다.

## 대상 독자

- 웹 개발 경험이 없는 비전공자
- 프로젝트를 어디서부터 읽어야 할지 모르는 학습자
- 개별 기술보다 「오늘도 가볍게」의 실제 동작을 먼저 이해하고 싶은 학습자

## 학습 방법

```text
1. 프로젝트의 전체 지도 보기
2. 사용자 요청의 전체 흐름 보기
3. 각 영역을 하나씩 확대하기
4. 실제 코드로 전체 흐름 다시 연결하기
```

## 문서별 안내

### 00. 프로젝트를 5분 만에 이해하기

서비스의 목적과 전체 구성을 가장 먼저 소개한다. 브라우저, 가비아, Vercel, 프론트엔드, Python
백엔드, Supabase가 각각 어떤 역할을 맡는지 큰 그림만 확인한다.

### 01. 사용자 행동으로 보는 전체 흐름

사이트 접속부터 로그인 확인, 기록 조회와 저장까지 사용자의 행동이 시스템을 통과하는 순서를
살펴본다. 처음에는 세부 기술보다 각 구성 요소가 언제 등장하고 다음 단계에 무엇을 전달하는지에
집중한다.

### 02. 프론트엔드

HTML·CSS·JavaScript·TypeScript의 역할부터 React의 컴포넌트·Props·State·이벤트를 차례로
학습한다. 이어서 Next.js App Router와 Server Component·Client Component가 이 프로젝트에서
어떻게 사용되는지 확인한다.

### 03. HTTP와 API

브라우저와 서버가 사용하는 요청·응답 규칙을 배운다. URL, HTTP 메서드, 헤더, JSON 본문, 쿠키,
상태 코드를 익힌 뒤 프로젝트의 `fetchApi()`가 실제 요청을 어떻게 보내는지 연결해서 본다.

### 04. 백엔드

Python API가 요청을 받고 입력값과 사용자를 확인한 뒤 데이터 저장을 지시하는 과정을 다룬다. API
핸들러, Pydantic 검증, 비즈니스 규칙, 오류 처리와 Vercel 서버리스 함수의 역할을 살펴본다.

### 05. 데이터베이스

Supabase와 PostgreSQL의 관계를 먼저 이해하고 Table·Row·Column 같은 기본 단위부터 학습한다.
`members`, `meals`, `weights`의 관계와 제약 조건, 조회·저장, 마이그레이션이 필요한 이유를
프로젝트 구조에 맞춰 살펴본다.

### 06. 인증과 인가

사용자 식별, 인증과 인가, 로그인 상태와 세션을 먼저 구분한다. 그다음 쿠키, 토큰, JWT를 하나씩
학습하고 Supabase Auth와 Python API가 로그인한 사용자를 확인하는 전체 흐름을 연결한다.

### 07. 인프라와 배포

도메인과 DNS의 차이부터 가비아의 A·CNAME 레코드가 Vercel을 가리키는 과정까지 알아본다. 캐시,
HTTPS, Vercel 배포, Supabase, 환경 변수와 로컬·Preview·Production 환경의 차이도 함께 다룬다.

### 08. 개발 작업 방식

프로젝트를 로컬에서 실행하고 변경 사항을 검사하는 방법을 소개한다. 필요한 도구와 주요 명령,
Git 작업 흐름, 데이터베이스 마이그레이션을 수정할 때의 주의점을 확인한다.

### 09. 실제 코드로 다시 연결하기

앞에서 배운 개념을 실제 파일과 함수에 연결한다. 접속과 세션 확인, 기록 조회와 저장, 달력 조회,
회원가입 같은 기능이 어떤 코드를 순서대로 지나가는지 추적한다.

### 10. 용어집

학습 문서에서 사용하는 핵심 용어를 한두 문장으로 빠르게 찾아볼 수 있다. 다른 문서를 읽다가 낯선
단어를 만났을 때 먼저 확인하고, 자세한 설명이 필요하면 연결된 문서로 이동한다.

## 문서를 읽는 방법

- 처음 학습한다면 `00`부터 번호 순서대로 읽는다.
- 이미 알고 있는 영역이 있다면 목차에서 필요한 문서를 골라 읽어도 된다.
- 실제 사용자 행동에서 코드를 추적하려면 `09`, 낯선 단어를 빠르게 찾으려면 `10`을 활용한다.
- 각 문서 마지막의 이해 확인 질문에 답하기 어렵다면 다음 문서로 넘어가기 전에 해당 장을 다시
  확인한다.
- 세부 기술을 외우기보다 프로젝트 전체 흐름에서 해당 기술이 맡은 역할을 먼저 이해한다.
